# 专业课达成度分析工作台

专业课达成度分析工作台是一款用于课程成绩统计与课程目标达成度分析的单文件网页工具。工作台可以根据平时成绩、期末分题型成绩和评价环节权重，计算学生综合成绩、课程目标达成度、班级统计结果及毕业要求指标点达成评价值。

当前版本：**1.01**

## 主要功能

- **导入前配置参数**：设置期末题型及满分、平时成绩分项及占比、综合成绩构成，以及课程目标对应的评价环节权重。
- **课程目标可增删**：可以添加、删除和重命名课程目标，并分别配置各评价环节的相对权重。
- **自动生成导入模板**：根据当前题型和平时分项生成 CSV 模板，表头包含学号、姓名、班级和各项原始成绩。
- **多种数据导入方式**：支持 XLSX、CSV 文件，也支持从 Excel 复制数据后直接粘贴。
- **中文 CSV 编码识别**：可识别 UTF-8、UTF-16 和中文 Windows 环境常见的 GBK 编码。
- **班级分类查看**：从导入数据的“班级”列读取班级，支持全部数据与单个班级切换。
- **结果表与散点图**：提供课程目标达成度、毕业要求指标点、个体数据、分班对比和学生明细，并为各班级、各课程目标生成逐生散点图。
- **本地下载**：支持下载学生明细 CSV、个体数据 CSV、单张散点图 PNG，以及通过浏览器打印或保存 PDF。

## 使用流程

### 1. 设置课程参数

在“课程设置”中依次完成以下设置：

1. 添加期末题型，并填写各题型满分。
2. 添加平时成绩分项，并填写分项满分和占比。
3. 设置平时成绩与期末成绩在综合成绩中的占比。
4. 添加课程目标，并设置各课程目标使用的评价环节及权重。

课程目标权重使用相对比例。程序会在每个课程目标内部自动归一化，因此填写 `0.25` 与填写 `25` 的相对效果相同。权重留空或填写 `0` 表示该环节不参与对应课程目标。

### 2. 生成并填写模板

点击“生成导入模板（CSV）”，然后在模板中填写学生数据。每名学生占一行，数据列包括：

- 学号
- 姓名
- 班级
- 各期末题型的原始得分
- 各平时成绩分项的原始得分

学号与姓名同时为空的行不会计入学生数据。未填写班级的记录会归入“未填班级”。

### 3. 导入并计算

将填写完成的 XLSX 或 CSV 文件拖入导入区域，或者点击“选择文件”。也可以直接从 Excel 复制数据区域并粘贴到文本框，再点击“解析并计算”。

如果 XLSX 文件包含多个工作表，可以在导入区域切换工作表。XLSX 解析依赖浏览器的 `DecompressionStream` 功能；如果当前浏览器不支持该功能，可以改用 CSV 或直接粘贴数据。

### 4. 查看与导出结果

结果区顶部的班级选项卡可以切换“全部数据”或某个班级。表格、学生明细和个体数据会随当前查看范围更新。

| 导出内容 | 格式 | 查看范围 |
| --- | --- | --- |
| 成绩与达成度学生明细 | CSV | 当前班级选项卡 |
| 个体数据 | CSV | 当前班级选项卡 |
| 课程目标达成情况散点图 | PNG | 每张图对应的班级与课程目标 |
| 分析结果 | 打印或 PDF | 当前页面结果 |

导出的 CSV 文件带有 UTF-8 BOM，便于使用 Excel 打开中文内容。

## 计算口径

### 平时成绩

平时成绩按各分项得分率加权计算，并转换为百分制：

```text
平时成绩 = Σ（分项得分 ÷ 分项满分 × 分项占比）÷ Σ分项占比 × 100
```

### 期末百分制

```text
期末百分制 = 各期末题型原始得分合计 ÷ 各题型满分合计 × 100
```

### 综合成绩

```text
综合成绩 = 平时成绩 × 平时成绩占比 + 期末百分制 × 期末成绩占比
```

### 课程目标达成度

```text
单生课程目标达成度 = Σ（评价环节权重 × 该环节得分率）÷ Σ评价环节权重
```

班级或全部学生的课程目标达成度取当前范围内学生个体达成度的平均值。课程目标达成度表中的“环节满分”和“平均得分”按百分制显示。

### 毕业要求指标点达成评价值

```text
达成评价值 = 目标达成权重 × 对应课程目标达成度
```

## 数据与隐私

成绩数据的解析、计算、筛选和图表生成均在本机完成。工作台不会把成绩数据上传到任何服务器。

独立 HTML 不依赖第三方 JavaScript 库、CDN 或后端服务，也不需要安装 Node.js 或 Python。下载文件后，成绩分析功能可以离线使用。
