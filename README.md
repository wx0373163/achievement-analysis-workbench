# 专业课达成度分析工作台

专业课达成度分析工作台是一款面向高校课程的成绩统计与目标达成度分析工具。该工具以单个 HTML 文件交付，不依赖服务器、数据库或第三方图表库；教师导入一份成绩表，即可得到综合成绩、课程目标达成度、毕业要求指标点达成评价值和逐生散点图。

当前版本：**V1.1**

| 形式 | 适用场景 | 位置 |
| --- | --- | --- |
| 独立 HTML | 免安装，用浏览器直接打开，可离线使用 | [index.html](./index.html) |

## 主要功能

- **参数先配置、数据后导入**：期末题型及满分、平时成绩分项及占比、综合成绩构成、课程目标评价环节权重，全部在导入前设定。
- **课程目标可增删**：目标数量不固定，新增目标后可单独勾选参与的期末题型与平时分项，并填写相对权重。
- **导出导入模板**：按当前参数生成 CSV 模板，表头与设置自动对应，避免手工改列名。
- **三种导入方式**：XLSX 文件、CSV 文件、从 Excel 复制后直接粘贴。
- **中文编码自适应**：自动识别 UTF-8、UTF-16 与 GBK 编码，中文 Windows 下导出的 CSV 可直接读取。
- **班级分组查看**：班级取自导入数据的“班级”列，可在“全部数据”与单个班级之间切换，表格、图表、明细同步变化。
- **逐生散点图**：为每个班级、每个课程目标各生成一张散点图，横轴为学生序号，纵轴 0–1.0，每张图可单独导出 PNG。
- **课程总评成绩汇总**：按课程总结表的字段口径输出总评概况、分数段分布、课程目标分值与权重、平时分项平均分四张表。
- **一键导出**：学生明细 CSV、个体数据 CSV、散点图 PNG、整页打印或另存为 PDF。

## 快速开始

### 第一步：设置课程参数

在“课程设置”区域完成四项内容：

1. 期末题型：填写题型名称与满分，可增删。
2. 平时分项：填写分项名称、满分与占比，可增删。
3. 综合成绩构成：设置平时成绩与期末成绩各占多少。
4. 课程目标：逐个设置目标名称，并为每个目标勾选评价环节、填写权重。

课程目标内部的权重按相对比例处理。程序在计算前会先做归一化，因此同一目标下填写 `0.25` 与填写 `25` 的结果相同；某项留空或填 `0` 表示该环节不参与这个目标。

### 第二步：生成并填写模板

点击“生成导入模板（CSV）”，得到一份空白成绩表。模板包含学号、姓名、班级，以及各期末题型和各平时分项的原始得分列。每名学生占一行。

学号与姓名同时为空的行会被跳过；“班级”列为空的记录归入“未填班级”。

### 第三步：导入并计算

把填好的文件拖入导入区域，或点击“选择文件”。也可以从 Excel 复制数据区域后粘贴到文本框，再点击“解析并计算”。

XLSX 若含多个工作表，导入后可在下拉框中切换。XLSX 解析依赖浏览器的 `DecompressionStream` 能力；若当前浏览器不支持，改用 CSV 或粘贴方式即可。

### 第四步：查看与导出

结果区顶部是班级选项卡。切换选项卡后，下方所有表格、图表和明细都会按当前范围重新计算。

## 结果区结构

| 顺序 | 区块 | 内容 |
| --- | --- | --- |
| 1 | 总体结果 | 班级选项卡、人数与平均分等指标、数据检查提示 |
| 2 | 分班对比 | 全员合计与各班级的平均成绩、各目标达成度 |
| 3 | 课程目标达成度 | 每个目标下各评价环节的权重、满分、平均得分与达成度 |
| 4 | 毕业要求指标点达成情况 | 指标点权重、对应课程目标、目标达成权重与达成评价值 |
| 5 | 班级达成情况分布 | 每班每目标一张逐生散点图 |
| 6 | 个体数据 | 每名学生一行，列出各课程目标达成度 |
| 7 | 学生明细 | 原始分、计算分与达成度的完整明细 |
| 8 | 课程总评成绩汇总 | 对应课程总结表中标注为黄底的字段 |

## 课程总评成绩汇总

该区块固定位于页面末尾，随班级选项卡联动，包含四张表：

1. **总评成绩概况**：应考人数、参与分析总人数、最高分、最低分、平均分，取值对象为综合成绩。
2. **分数段分布**：按 100~90 优秀、89~80 良好、79~70 中等、69~60 及格、低于 60 不及格五档统计人数；百分比的分母为参与分析人数，保留两位小数。
3. **课程目标考核的具体分值与权重**：每个课程目标一行起，先列期末考试（目标内各期末题型合并为一个环节），再列该目标使用的平时分项；四项内容为目标分值、平均分、权重和目标达成评价值。
4. **平时成绩分项平均分**：列出全部平时分项，包含未纳入任何课程目标的项目，便于核对。

表三中的“目标分值”和“平均分”均为百分制；“权重”为目标内部归一化之后的数值，同一目标下各环节权重合计为 1。

导入数据没有缺考字段，因此“应考人数”与“参与分析总人数”取同一数值。如需区分缺考，请在导入表中补入相应记录后再统计。

## 计算口径

### 平时成绩

```text
平时成绩 = Σ（分项得分 ÷ 分项满分 × 分项占比）÷ Σ分项占比 × 100
```

### 期末百分制

```text
期末百分制 = 各期末题型得分合计 ÷ 各题型满分合计 × 100
```

### 综合成绩

```text
综合成绩 = 平时成绩 × 平时占比 + 期末百分制 × 期末占比
```

### 课程目标达成度

```text
单生目标达成度 = Σ（环节权重 × 该环节得分率）÷ Σ环节权重
```

班级或全体范围内的目标达成度，取范围内学生个体达成度的算术平均值。课程目标达成度表展示的环节满分与平均得分均为百分制，鼠标悬停可看到原始满分与原始平均分。

### 毕业要求指标点达成评价值

```text
达成评价值 = 目标达成权重 × 对应课程目标达成度
```

| 导出内容 | 格式 | 范围 |
| --- | --- | --- |
| 成绩与达成度学生明细 | CSV | 当前班级选项卡 |

## 数据与隐私

成绩数据只在本机内存中处理，不上传、不联网、不写入远端存储。独立 HTML 不引用 CDN 或任何外部脚本，断网状态下功能不受影响。

安装版默认安装到当前用户目录 `%LOCALAPPDATA%\Programs\AchievementAnalysis`，不需要管理员权限。

## 系统要求

- 独立 HTML：Chrome、Edge、Firefox 等现代浏览器；XLSX 导入需要浏览器支持 `DecompressionStream`。
- Windows 安装包：Windows 10 或 Windows 11，64 位。

## 卸载

打开“控制面板 → 程序和功能”，找到“专业课达成度分析工作台”后选择卸载。若“设置 → 应用 → 已安装的应用”中未列出该程序，以控制面板列表为准，两者读取的是同一份卸载注册信息。
